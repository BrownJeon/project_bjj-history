피드백을 모아 보고, 연습을 이어가요

홈 최근 3개 · 전체 목록과 검색 · 기술·상황 선택 · 연습 결과 수정/삭제

현재 → 제안

홈: 정리 상태만 표시 → 정리 상태와 훈련 상태를 함께 표시하고 전체 목록으로 이동.

입력: 기술·상황 직접 입력 → 등록 기술 검색·선택, 상황 체크.

연습 결과: 저장만 가능 → 기록 옆 수정·삭제, 같은 폼으로 편집.

확인할 흐름

  • 홈에는 날짜가 최근인 피드백 3개만 표시합니다.
  • 전체 보기에서 검색·즐겨찾기·완료와 기술 조건을 조합합니다.
  • 보우 앤 애로우 카드에서 ‘됐음’ 기록을 수정·삭제하면 훈련 상태가 다시 계산됩니다.
  • 기술 검색에는 등록된 기술만 표시합니다. 상황은 복수 선택, 기타만 직접 입력합니다.

변경 범위가 구체적으로 정해져 별도 A/B 선택은 없습니다. 수업·기간별 복기 화면은 기존 구성을 유지합니다.
