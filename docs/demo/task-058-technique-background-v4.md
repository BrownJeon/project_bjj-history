# 기술트리 이미지 배경 비교 데모 v4

확정한목록48px·같은정보항목72px·상세최대224px를유지하고니컷추천배경3종을추가했다.

- 차콜#15171E/블루그레이#242836/짙은청록#18312C + 기존주황/앱배경,총5가지다. 목록·상세의버튼이선택상태를공유한다. 기본선택은차콜이며선택확정은아니다.
- 새3종은내장imagegen으로배경분리한하나의투명PNG에정확한CSS배경색을적용한다. 새후보끼리는같은캐릭터픽셀/크기를사용하며별도의컬러PNG3장을생성한방식이아니다.
- 원본주황/앱배경2PNG·v1~v3·운영소스는보존했다. 데모의추천3색추가도구만두줄버튼으로확장했다. 실제앱화면구성과데이터연결방식은기존격리시안과같다.
- 3추천색목록48px/카드72px·전체5색상세224px실측,360/390/412가로넘침없음·버튼최소44px·정상로드·콘솔0·새UI기계검사0. 새3색224px상세에서인물잘림/눈에띄는색테두리는관찰하지않았다.
- 주소: http://127.0.0.1:63686/ . HTML파일직접열기도가능. 전체PNG인라인의약7.1MB검토본이며운영용최적화/앱버전/DB/배포변경없음.
