# task-054 운영 적용·배포

사용자가 관장 분류 채택·연결테이블1개 생성·신규기술110/연결110 등록·이번변경만커밋/push·웹배포의Codex수행을승인했다. 기존60행은보존하고모호21개는후속확정,챔피언구현은제외한다.

실제DDL/DML검증은완료됐으며원시스냅샷/개인매칭/결정/백업은비공개로보관한다. 이저장소의관장후보기본값은빈목록이다. 운영스크립트사용자는 --snapshot 및 --decisions 비공개파일을명시하고, 개인관장대응을사용할때 --coach-candidates 파일을지정하거나 --no-coach-candidates를사용한다.

배포는 docs/deploy-order.md 정본·선택변경만origin/main에push·blue/green결과판정절차를따른다. 다른로컬커밋과dirty변경은보존한다. 자동restore는신규기술/그연결을삭제하지않는다. 운영HTTP/실기기확인은실행사실과미확인을구분한다.
