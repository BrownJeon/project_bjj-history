## DB 영향

새 테이블 `technique_reference_links` 하나를 추가하는 DDL 초안이다. 사용자를 가리키는 FK와 기술을 가리키는 FK는 이 보조 연결 기록만 cascade 삭제한다. 기존 users/techniques 테이블에 ALTER/DROP은 하지 않는다. 이름 스냅샷을 저장하여 기술의 의미를 바꾸는 이름 수정 뒤 이전 설명을 재사용하지 않는다. 실제 전체 DDL과 검사 규칙은 backend/scripts/task-054-reference-links-schema.js가 정본이다.

110개 신규 기술은 user3에 source 이름·최종 제안 분류·빈 개인메모·빈 포지션/태그/개인영상링크 배열·즐겨찾기false로 생성한다. 날짜는 명시 기록한다. 원래 POST의 영상 AI 자동 분석을 호출하지 않는다. 관장 설명159개와 앞뒤/관련 관계는 버전 관리되는 공개 catalog에 두어 개인 메모를 덮지 않는다. 선수/챔피언 데이터나 화면은 생성하지 않는다.

## 실행 순서 (승인 후)

1. 실제 운영 환경의 ref/도구·DB 대상·소유자3을 재확인한다. env 값은 화면/로그/문서에 출력하지 않는다. 빈 host/database/user/port와 잘못된 포트는 거부하고 app dotenv/default DB 설정에 의존하지 않는다.
2. 현재 read-only 기술 ID/이름 스냅샷으로 계획/지문을 재대조한다. ID/이름/행수가 변하면 기존 결정 파일을 그대로 적용하지 않고 중단하여 변경된 대상만 정리한다. 개인메모만 바뀐 경우에는 잠금 시점의 최신 메모를 그대로 보존한다.
3. schema `--verify`로 메타데이터를 확인한다. 없을 때만 별도 승인된 schema `--apply --confirm-database`를 실행한다. 기존 비호환 테이블은 임의 ALTER하지 않는다. CREATE 성공 후 검증 실패는 DDL implicit commit 때문에 자동 취소되지 않으며 생성후검증실패 상태로 보고한다.
4. 승인된110개 decision + 고정plan SHA + user 확인 + database 확인 + 새 백업경로를 모두 지정한 경우에만 apply. FOR UPDATE·트랜잭션 안에서 snapshot 지문·소유자·기존행 보존을 검사한다. SQL 오류·백업 오류·보존 위반은 커밋 전 실패로 중단한다.
5. 결과의 새 기술110·연결110·기존60 불변과 다른사용자 변경0을 대조한다. 캐시/API 응답·새 테이블/기술 FK·앱 설명/다중연결을 확인한 뒤 배포 단계로 진행한다. 실제 배포는 docs/deploy-order.md 정본, 독립 Reviewer→QA PASS 및 사용자 승인 범위를 따른다.

## 백업·복원 범위

백업은 Git 밖 운영 계정의 비공개 경로에 둔다. 신규 디렉터리0700·파일0600. `<backup>.pre-write`에는 변경 전 기록, `<backup>`에는 커밋 직전 기록과 이번에 생성한 ID/이름/연결을 저장한다. 두 경로 모두 배타적 신규 생성이며 기존 파일·심볼릭 링크를 덮어쓰지 않는다. 로그는 별도 경로의0600 새 파일이며 백업 경로와 겹칠 수 없다. DB커밋 뒤 부가 로그 기록 실패는 DB실패/자동롤백으로 보고하지 않는다.

**자동 restore는 기존 기술에 이번에 붙인 미변경 연결만 되돌린다. 추가 기술110개와 그 연결은 이후 기록 보호를 위해 유지한다.** 코드 롤백도 DB 데이터 삭제를 뜻하지 않는다. 기술 삭제가 필요하면 이후 수업·영상·연구 등의 사용을 확인한 별도 정리 판단이 필요하다. 이미 적용한 데이터 전체를 자동 삭제하는 원복으로 승인하지 않는다.

## 현재 검증 경계

실제 운영 DB에 DDL/apply/restore를 실행하지 않았다. 이 Mac에는 격리 MariaDB/Docker 런타임이 없어 실제 SQL 엔진 통합 검증은 하지 못했다. 합성 어댑터/드라이버 구성/SQL 바인딩/메타데이터 fixture·파일 권한 테스트와 실제 React build/합성 API 브라우저 검증을 구분해 최종 결과에 기록한다. 실제 SQL 반영 결과·인증된 운영 UI·물리 Android 확인은 현재 완료 사실이 아니다.
