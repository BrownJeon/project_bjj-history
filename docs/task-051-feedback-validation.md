# task-051 실제 피드백 기능 검증

구현 기준은 사용자 승인 데모 v5다. 사용자는 승인 기록 장애와 별개로 동일 v5 기준의 화면 구현을 계속하도록 명시했다. 해당 지시와 도구의 BLOCKED 상태를 작업 이력에 구분해 기록했으며, 승인 receipt·신뢰 기록·과거 hook 사건을 만들지 않았다.

검증한 앱 코드 커밋: `32fe6ccb0cc8394b615e00b49e41da16c34b8249`. 이 문서 작성은 앱 코드 변경을 포함하지 않는다. 운영 DB 적용·push·배포는 실행하지 않았다.

## 구현 범위

- 수업과 독립된 피드백 입력, 홈·복기 진입 및 수업 헤더의 `+수업`/`+피드백`. 기존 캘린더·수업목록과 `ClassEditPage` 편집기는 보존했다.
- 현재 확정 답변을 반영하는 한 번에 한 질문, 이전 질문·미제출 초안·변경 전 경로 보관, 저장·재개와 동시 편집 충돌 처리.
- 원문·활성 보완 답변을 교정점/연습법에 통합하는 관장 CLI, 현재 출처 직접 인용 검사, 미래 연습 제안 표시, 이전 요약 보존/갱신 필요 상태.
- 기존 참고영상 필터, 필터 적용 후 5개 페이지, 페이지/필터 밖 선택 보존, 사용량이 포함된 기존 캐시로 공용 `ClipDetailModal` 재사용.
- 실제 주간 과제 지정·유지·교체, 연습 결과와 기간별 복기. 기본 달력 월, 전체/주/월/직접선택을 같은 적용 범위로 조회한다.

## Root의 실제 브라우저 관찰

테스트 대상은 실제 `web/src`를 실행하는 `http://127.0.0.1:63674/recall`이다. Feedback API와 DB는 실제 구현이며, 인증·AI·기존 보조 API는 명시적인 합성 fixture다. 지원하지 않는 기존 추천/조건 검색/연구 목록은 501이다. 실제 운영 로그인·원격 영상 재생을 검증한 것이 아니다.

- 캘린더/수업목록 탭과 기존 수업 추가 편집기 표시를 확인했다. 캘린더 11월 1일을 선택해도 피드백은 당시 오늘인 11월 4일의 빈 독립 입력으로 열렸다. 수업 저장/실제 기존 CRUD를 검증한 것은 아니다.
- 7개 영상의 5+2 페이지, 1/7번 선택 후 검색 결과가 1개로 줄어도 총 선택 2개 보존, 선택 해제와 공용 상세의 실제 사용량 표시를 확인했다. 상세에서 Escape로 닫으면 피드백과 필터/선택·포커스가 보존됐다.
- 저장 후 닫고 다시 열어 질문을 재개했다. 두 번째 답변의 초안을 작성하고 첫 질문으로 돌아간 뒤 동일 답변으로 전진했을 때 초안이 복원됐다.
- 첫 답변 수정 후 이전 질문 경로와 미제출 초안이 보관 이력에 남는 것을 확인했다. 현재 경로를 정리하면 교정점·연습문장과 인용에 활성 답변이 나타났다.
- 기존 과제 유지/교체를 선택했고 실제 격리 DB의 과제 1이 마감 이력에 남고 과제 2/노드 2/프로젝트 2가 생성된 것을 API로 확인했다.
- 연습 실패 결과를 저장하면 기존 카드가 갱신 필요 상태가 됐다. 합성 AI 1회 실패를 주입했을 때 기존 카드/입력이 보존됐고, 재시도로 최신 카드가 복구됐다.
- 전체/주/월/직접선택의 적용 기간과 집계 변경을 확인했다. 역전된 직접 기간은 오류로 차단되고 기존 적용 범위를 유지했다. 피드백 연습 실패와 스파링 실패는 분리 표시됐다.
- 360/390/412px에서 카드·직접 기간 입력의 가로 넘침이 없었다. 임시 viewport는 원래 크기로 복원했고 브라우저 탭을 인계 상태로 남겼다.
- fixture 서버를 세션과 분리해 재기동한 뒤 피드백 4의 활성 답변 2개·이력 1개·영상 1·결과 1개와 최신 요약이 보존된 것을 확인했다.

화면 증거와 서비스 수명 정보는 현재 채팅 artifact 폴더의 `task-051-feedback-card-390.jpg`, `task-051-recall-390.jpg`, `task-051-preview-services.json`에 있다. 서비스는 루프백 전용 검증 환경이다.

## 외부 검토·범위·남은 한계

- C1은 `skipped(checkpoint_not_selected)`였다. 앞선 부분 C2는 root의 기준 커밋 지정 오류로 `incomplete(task_base_mismatch)`였고 provider 호출·본문 전송이 없었다.
- 전체 UI 완료 후 새 C2 판정에 따라 공식 검토를 1회 요청했으나 `incomplete(sensitive_content, attempt=null)`로 중단됐다. 원인은 스키마 스크립트의 환경변수 참조 구문이 credential-like-assignment 검사에 걸린 것이다. provider 호출·선택 본문 provider 전송·검증된 findings는 없고, 내부 Reviewer가 채택할 외부 지적도 없었다. 재시도·guard 완화·redact는 하지 않았다.
- 외부 전송 후보 22파일 중 기존 실제 훈련 수량/날짜 주석이 있는 RecallPage를 제외해 최종 21파일을 고정했다. 로컬 보안 확인에서 읽은 범위와 외부 전송 범위는 별도로 기록했다. 외부 21파일 및 제외 범위는 외부 검토 미완료다.
- fixture 담당자가 `backend/src/services/clipUsage.js` 1–145행을 사전 추가 허용 없이 읽은 범위 이탈이 있었다. 해당 파일 변경·실행·외부 전송은 없었다. 사실과 영향을 README/task에 남겼으며 이후 추가 범위를 확인했다.
- 실제 Android/WebView·한국어 IME 기기·cross-origin iframe 내부 키보드·운영 로그인/DB/배포·실영상 재생은 미검증이다. 비Modal 패널의 최초 동시 마운트 native backStack 경로는 도달 경로가 확인되지 않은 기존 주의사항으로 남겼다.
- React Router 미래 플래그·큰 번들 경고와 기존 Card/WeeklyTaskCard의 border/borderLeft 개발 경고가 관찰됐다. 후자의 두 파일은 기준 커밋과 현재 커밋의 Git blob이 같아 이번 변경 대상이 아니다. 이를 새 기능 완료의 필수 개선으로 확대하지 않았다.

## 운영 경계

공유 NAS DB는 수정하지 않았다. 새 `feedback_records` 스키마 스크립트는 기본 dry-run이고, 연결 검증/적용은 명시 환경과 별도 승인된 운영 절차가 필요하다. 코드 구현 완료를 DB 적용·배포 완료로 확대하지 않는다.
