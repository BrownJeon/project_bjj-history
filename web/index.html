BJJ 훈련 일지

주짓수(BJJ) 훈련을 체계적으로 기록·분석하는 개인 웹앱. 수업·드릴·스파링·기술 트리·게임플랜·참고영상을 한 곳에서 관리하고 AI 코치/분석으로 약점 진단·개선 제안을 받습니다.

주요 화면

  • 📅 캘린더
    월별 수업·드릴·스파링 기록과 일자별 수련 체크
  • 🥋 기술 트리
    포지션·기술·디테일 카드 관리, 기술명 기반 영상 자동 연결
  • 🔗 기술 체인
    기술 간 전환 흐름과 단계 정의
  • 🎯 게임플랜
    노드·엣지 기반 의사결정 플로우 설계
  • 🎬 참고영상
    YouTube/Instagram 클립 라이브러리 + AI 영상 분석
  • 🤖 AI 코치
    기간 진단 리포트와 다음 주 훈련 포커스 플랜 자동 생성

디자인 / UX 특징

  • 모바일 우선 — 갤럭시 S25+ Chrome 폭(~412px) 최적화, 데스크탑 다열 그리드
  • 하단 5탭 고정 네비게이션 (캘린더 / 기술 / 체인 / 게임플랜 / 영상)
  • 다크모드 자동 (`prefers-color-scheme`)
  • 주요 색상 — primary #1D9E75 (그린), accent #EF9F27 (앰버 — 즐겨찾기)
  • 모달 기반 편집 (수업/스파링/기술/영상/게임플랜)
