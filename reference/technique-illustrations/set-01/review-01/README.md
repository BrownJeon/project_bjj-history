- 도구: 기본 내장 `image_gen` / `imagegen` 스킬. CLI·API 키 경로 미사용.
- 캐릭터: 승인된 set-01 파란 도복(흰 머리·파란 눈), 흰 도복(검은 머리·갈색 눈), 두 명 모두 브라운 벨트.
- 표현: 기존 싱글엑스 샘플의 오렌지 배경·입체감 있는 일러스트. 각1254×1254 PNG, 글자/화살표 없음.

입력 역할은 캐릭터 시트2장(외형), 해당 기술 원본1장(자세·카메라), 기존 싱글엑스 샘플1장(표현·배경)으로 분리했다. 참고사이트의 원본 비교 이미지는 작업용 참고자료로만 보관하며 이 폴더에 복제하지 않는다. 승인 캐릭터 원본과 기존 샘플을 덮어쓰지 않았다.

`manifest.json`에 이미지 크기·bytes·SHA256·프롬프트와 기술 키를 기록했다. 기본 생성 경로의 원본은 보존하고 프로젝트 내 복사본을 별도로 저장했다.

캐릭터 일관성·표현·기술 자세에 대한 사용자 검토 후 수정 기준과 전체 제작 여부를 정한다. 이 파일은 사용자 승인 또는 실제 수업용 설명의 최종 검수를 뜻하지 않는다. 앱 새 빌드/배포나 APK 전달을 하지 않아 앱 버전을 올리지 않았다. 참고영상 수집 작업도 보류 유지한다.

## 관장 이미지 검토

- 니컷: 상체 압박·절단 무릎·바깥지지발 및 사지 연결 확인.
- 암바: 한쪽 손목과 머리/상체 다리 제어는 식별되나 **팔꿈치와 골반의 접점은 무릎에 가려 확인이 제한**된다. 사용자 검토 시 구도 보완 여부를 정한다.
- 백 컨트롤: 앞뒤 밀착·상체 잠금·안쪽 훅과 사지 연결 확인.

명백한 추가 사지나 연결 단절 등 재생성이 필요한 결함은 관찰하지 못했다. 이는 원본 및 생성 샘플의 육안 검토이며 사용자 승인·모든 자세 정확성 보증을 뜻하지 않는다.
