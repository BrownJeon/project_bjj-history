# task-018 — 첫 음성분석에만 날짜 라벨이 빠지던 버그

## 사용자 보고

> 수업기록에서 음성파일을 업로드했을 경우 전체 메모에 기록할 때, **첫 번째 음성분석의 경우 날짜가 없는데 두 번째 음성분석할 때부터는 날짜가 표기**되고 있어서, 첫 번째 음성분석할 때도 날짜를 표기해줘

## 원인 — `backend/src/routes/voice.js:66-69`의 CASE 분기

```sql
note = CASE WHEN note IS NULL OR note = '' THEN ?               -- 첫 분석: note만, 라벨 없음
            ELSE CONCAT(note, '\n\n[9/5 음성 분석]\n', ?) END    -- 두 번째부터: 라벨 붙음
```

첫 분석 시점에는 전체 메모가 비어 있어 `THEN` 분기를 타는데, **거기엔 `[날짜 음성 분석]` 라벨이 아예 없다.** 두 번째 분석부터는 `ELSE` 분기라 라벨이 붙는다.

결과적으로 메모 맨 앞의 첫 덩어리만 **어느 날 음성인지 알 수 없는 상태**로 남았다.

- 날짜(`trainedDate`)는 프론트가 항상 보내고 있었고(`ClassEditPage.jsx:122`), `label` 생성(`voice.js:59-61`)도 정상이었다. **오직 첫 분기에서 label을 안 쓴 것**이 원인.

## 수정

`THEN ?` → `THEN CONCAT(?, ?)`로 바꿔 첫 분석에도 라벨을 앞에 붙인다. 첫 분석은 위쪽 빈 줄 없이 라벨로 시작한다.

## 검증 (실제 DB, admin 계정 픽스처)

**네거티브 컨트롤 — 구버전으로 버그 재현:**
```
[구버전] 1차 분석 직후
델라히바 훅 각도 교정          ← 라벨·날짜 없음
...
[구버전] 2차 분석 후
델라히바 훅 각도 교정          ← 앞부분 여전히 날짜 없음
[9/6 음성 분석]               ← 두 번째만 날짜 있음
```

**수정 후:**
```
[신버전] 1차 분석 직후
[9/5 음성 분석]               ← 날짜 표기됨
델라히바 훅 각도 교정

[신버전] 2차 분석 후
[9/5 음성 분석] ... [9/6 음성 분석]   ← 둘 다 있음
```

**회귀 — 사용자가 직접 쓴 메모가 있는 수업에 첫 분석:**
```
사용자가 직접 적은 메모        ← 보존됨

[9/5 음성 분석]
델라히바 훅 각도 교정
```

- 테스트 수업 3건은 전부 admin(user_id=1)으로 만들고 삭제(잔존 0건).
- `pm2 restart bjj` 후 `/health` 200. 실사용자 데이터 무변경(classes 29 / clips 133).

## 남은 것

- **이미 저장된 기존 메모는 소급 수정하지 않았다.** 과거 첫 분석분에는 여전히 날짜 라벨이 없다. 사용자가 원하면 별도 요청 시 처리 가능(수업별로 `voice_jobs.trained_date`를 조회해 앞에 라벨을 삽입하는 방식).
- `trainedDate`가 없으면 라벨이 `[음성 분석]`(날짜 없음)이 된다. 현재 프론트는 항상 날짜를 보내므로 실사용에서는 발생하지 않는다.
