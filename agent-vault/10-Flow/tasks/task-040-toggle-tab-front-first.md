# task-040 — 하단 토글 탭: 다른 탭에서 넘어오면 항상 앞 화면

## 사용자 요청 (2026-09-14)
> "다른 메뉴를 갔다가 이동시 무조건 앞에 메뉴로"
- 대상: 하단 토글 탭 3쌍(수업↔복기 · 기술↔영상분석 · 연구↔분석).
- 예) 홈 → 수업 → 복기 → 홈 → **수업 탭** = 예전엔 복기(마지막에 보던 쪽), 이제는 **수업**.

## 변경 (웹만, APK 재설치 불필요)
- `web/src/utils/toggleNav.js` `nextTarget` — 짝 밖(다른 탭에서 넘어옴) 분기를 "저장된 last" → **항상 앞(`pair.front.to`)** 으로 변경.
- 같은 탭 재클릭 토글(앞 → 뒤, 뒤 → 앞)은 그대로.
- `storage` 인자·`lastKey` 기록은 호출부 호환을 위해 남김(기록만 하고 이동에는 쓰지 않음).
- 서빙 번들 `index-yMEX_KZk.js`.

## 검증 (Leader 직접 실행)
- 실제 모듈 import 사용자 시나리오 **8/8**.
- 운영 UI 에서 CDP 로 실제 탭 클릭 **6/6** — 안쪽 메뉴(복기·영상분석·분석)에 들어갔다가 다른 탭 → 돌아오기 포함.
- 옛 [[task-023-toggle-nav-generalization]] QA 하네스: "last 기억" 을 기대하던 **5건만 의도대로 실패**, 나머지 통과(회귀 없음).
- 사용자 실기기: 앱 재시작 후 **"종료 후 다시 해보니 의도한대로 동작했어."**

## 참고
- 옛 task-023 QA 의 "last 기억" 기대 5건은 이제 사양과 다르다 — 그 하네스를 다시 쓸 일이 생기면 기대값을 "짝 밖 → 앞"으로 고칠 것.

## 최종 요약
**하단 수업·기술·연구 탭을 다른 탭에서 누르면 항상 앞 화면(수업·기술·연구)이 열립니다.** (배포·푸시 완료)

- 같은 탭을 한 번 더 누르면 지금처럼 뒤 화면(복기·영상분석·분석)과 번갈아 바뀝니다.
- 웹만 바뀌어 앱 재설치는 필요 없었고, 휴대폰에서 앱을 다시 켠 뒤 의도대로 동작하는 것을 확인해 주셨습니다.
