워크스페이스·프로젝트 지침과 사용자 지시가 이 스킬보다 우선한다. 확인되지 않은 항목을 목표·결정으로 올리지 않는다.

필요한 기능과 사용자가 정한 제약을 정리한다. 하위 에이전트를 부르지 않고 현재 세션에서 순서대로 찾는다.

1. 현재 저장소에서 관련 코드·테스트·의존성과 기존 사용 예를 찾는다. 기존 구현이 요구를 충족하면 근거 경로를 제시한다.
2. 워크스페이스의 `.claude/tools`와 공용 스킬 목록에서 같은 기능을 찾는다.
3. `adoption/REGISTRY.md`에서 검토·시범·보류·기각 이력을 찾는다. 재검토가 필요하다면 기존 판단이 달라질 근거를 제시한다.
4. 외부 검색이 필요하면 워크스페이스의 `adoption/ADP-011-ecc-analysis-skills/20-결정.md`에서 D-02를 확인한다. 사용자가 허용 범위를 승인한 후 그 범위 안에서만 실행한다. 승인 전에는 로컬 탐색 결과와 추가로 확인할 항목을 보고한다. 회사 코드, 비밀, 내부 식별자, 개인정보는 어떤 경우에도 검색어에 넣지 않는다.

기능 적합성, 호환성, 유지보수, 라이선스와 의존성 비용을 근거로 비교한다. 조회하지 못한 출처와 미확인 항목을 구분한다. 외부 후보는 설치·실행 없이 근거와 함께 `/신규도입`으로 넘긴다.
